# Evidencias del proyecto

Estas capturas documentan configuraciones y resultados observados durante el desarrollo del prototipo.

1. `01_arquitectura_workflow.png`: vista del workflow principal. La captura muestra el circuito y un aviso de ejecución, pero no debe interpretarse por sí sola como evidencia de que todos los nodos completaron el recorrido.
2. `02_salida_AI_Agent.png`: salida observada del nodo AI Agent para una consulta de prueba.
3. `03_actualizacion_Google_Sheets.png`: ejecución correcta del nodo Update row in sheet y datos visibles en su salida.
4. `04_configuracion_Error_Trigger.png`: configuración del workflow independiente con Error Trigger. Esta captura acredita la presencia/configuración del trigger, no una prueba integral de notificación o recuperación.
5. `05_error_credencial_Google_Sheets.png`: fallo observado por credencial de Google Sheets que requería reconexión. Es evidencia de un fallo ocurrido, no de una prueba controlada de todos los escenarios de error.
